# OG Tools v0.7 — نسخة تطوير شخصية لـPremiere Pro 2026

**الجديد في 13 نوفمبر 2026:** 8 أنماط كابشن متحركة بتوقيت الكلمة بالعربي والإنجليزي (بمكتبة faster-whisper الاختيارية)، 8 حركات Creator Zoom بإطارات Keyframes على الكليب المختار في كود UXP، وخمس منحنيات Speed Ramp بتنتج ملف فيديو جديد مع الصوت، واكتشاف سكوت الجزء المحدد من الكليب بدل تحليل الملف كله. **50 اختبار نجح خارج Premiere**؛ تشغيل الإضافة نفسها داخل Premiere لم يُختبر بعد.

اقرأ `RELEASE_NOTES_v0.7.md` لحدود كل وظيفة ومتطلبات تشغيلها.

النسخة دي مش مجرد بانل 21 زرار: فيها محرك حقيقي لتوليد ملفات فيديو/صوت/نصوص وأدوات محلية. لكنها **مش المنتج النهائي المكافئ بالكامل لـVOLT**، ومش أداة مثبتة ومختبرة داخل Premiere لحد دلوقتي.

## ملخص المنفذ

- **16 وحدة محلية**: حركات نصوص (30 preset)، 12 ستايل للنص، عنوان 2.5D، نصوص على قوس كصورة، فيديو رسم متحرك، 16 انتقال فيديو، 12 مؤثرًا صوتيًا، قص السكوت وإخراج نسخة جديدة، تنظيف الصوت والبودكاست، Speed Ramp بثلاث مراحل، تنظيم ملفات المشروع بنسخ آمن، خمسة أدلة سوشيال، مكتبة 22 أيقونة، 6 منحنيات Easing، كاروسيل متحرك.
- **4 وحدات بتحتاج مكتبات إضافية**: Whisper للكابشن، rembg لإزالة خلفية الصور، OpenCV لتتبع الحركة إلى CSV، yt-dlp لتنزيل مواد مسموح استخدامها.
- **ميزة مش منفذة**: البحث عن الأصول على الإنترنت من داخل البانل.
- قص السكوت عنده كمان وضع Premiere XML من خلال auto-editor الاختياري؛ الوضع ده **لم يختبر** هنا بسبب عدم تثبيت الأداة.

## مهم تعرفه

كل الأصول بتتولد في ملفات جديدة؛ الإضافة **مش بتقص التايملاين بنفسها**. استيراد الملفات إلى Project Bin مكتوب باستخدام API رسمي، بس لسه محتاج اختبار داخل Premiere 2026. القوالب المتحركة فيديو ProRes بخلفية شفافة، مش MOGRT قابل لتغيير النص بعد ما تضيفه.

**الاختبارات اللي نجحت هنا:** 25 اختبار Python، بتشمل إنتاج وفحص ملفات حقيقية وطلب تشغيل من واجهة الخدمة المحلية، بالإضافة لفحص JavaScript وManifest. بيئة الاختبار هنا Linux وليست Premiere على Windows. محاولة تشغيل معاينة البانل في متصفح آلي اتمنعت بقيود البيئة؛ بالتالي البانل نفسه مش معتمد بصريًا أو داخل Adobe.

## المحتويات

- `plugin/` — واجهة UXP للـ21 أداة.
- `engine/` — محرك محلي لمعالجة الميديا واستدعاء الأدوات المفتوحة المصدر.
- `examples/` — أمثلة فيديو عربي وإنجليزي + صور للستايلات.
- `tests/` — اختبارات وحدات وتجارب FFmpeg.
- `.github/workflows/test.yml` — اختبار GitHub Actions لو المشروع اترفع على GitHub؛ لم يتم تشغيله هناك حتى الآن.
- `START_OG_TOOLS_WINDOWS.bat` — تشغيل المحرك المحلي (يحتاج Python وFFmpeg).
- `OPTIONAL_AI_SETUP_WINDOWS.bat` — تثبيت المكتبات الاختيارية.

## التشغيل التقني

1. تثبيت Python 3.11+ وFFmpeg (لو مش موجودين).
2. تشغيل ملف `START_OG_TOOLS_WINDOWS.bat`؛ هيجهز بيئة Python وينزل Pillow لو ناقص.
3. من Premiere: تفعيل `Settings > Plugins > Developer Mode` ثم Restart.
4. من Adobe UXP Developer Tool إضافة `plugin/manifest.json` والضغط على Load.
5. البانل يقدر يختار ملفات، وينتج ملفات جديدة، ويحاول يستوردها داخل الـProject.

**مفيش ملفات أو تمبلتس محمية من VOLT ضمن المشروع.** المكونات من GitHub المستخدمة بشكل مباشر هي واجهات أدوات اختيارية منفصلة حسب تراخيصها. التفاصيل والمصادر: `README.md` و`THIRD_PARTY.md`.

## جديد v0.6 — Native Keyframe Studio (بدون رندر)

المستخدم يطلب الحركة نفسها والـKeyframes، مش ملف MOV. لهذا أضفنا **24 preset حركة بنظام Keyframes أصلية** على أي عنصر فيديو/Graphic محدد داخل التايملاين، طالما Premiere UXP يعرض له خصائص قابلة للتحريك مثل Position أو Scale أو Opacity أو Rotation. 

- اختر عنصر **Text / Graphic / MOGRT قابل للتعديل** داخل Premiere (ولا تختار فيديو رندر من OG Tools).
- افتح OG Tools > **Native Keyframe Studio**، اختر الحركة والمدة، واضغط **Inspect selected** لمعرفة خصائص العنصر؛ خصائص Motion/Opacity تُحدد تلقائيًا حين يتعرف عليها البرنامج، ويمكن اختيارها يدويًا.
- اضغط **Apply real keyframes to selected clip**. الحركات تُطبّق على العنصر في الـSequence باستخدام Adobe ComponentParam Action APIs، وتظهر ضمن Effect Controls (إذا كانت الخصائص مدعومة). النص الأصلي يظل قابلًا للتحرير من أدوات Premiere إن كان Editable Graphic/MOGRT من البداية.
- المنفذ حاليًا: Fade In/Out، Slide، Zoom، Pop، Bounce، Elastic، Rotation، Spin، Drift، Drop، Float، Pulse، Shake، Tilt، Overshoot (24 presets). Presets الخاصة برسم الحروف أو Mask Reveal أو الكلمات ليست قابلة للتطبيق كنفس الحركة على نص كامل عبر Motion/Opacity وحدها؛ في النسخة السابقة تظل كمخرجات MOV غير قابلة لتعديل Keyframes النص.
- يوجد تحكم في المدة (افتراضي 1.2s) وعدد Keyframes لكل خاصية (9 / 13 / 21). المنحنيات معبر عنها بـKeyframes متعددة، لا Bezier handles أصلية.
- الأمان: نرفض العملية لو الخاصية فيها Keyframes بالفعل؛ لا نكتب فوق عملك ولا نقسم النص أو نلغي الخلفية.

**حد الاختبار**: اختبارات Node.js تحاكي واجهات Adobe الأصلية للتحقق من أن أوامر الإضافة تنشئ Native Actions وتختار القيم الصحيحة وترفض الكتابة فوق Keyframes سابقة. لم يتم تشغيلها أو اعتمادها داخل Premiere Pro 2026 نفسه؛ قد تختلف أسماء ومكوّنات Motion/Opacity حسب الـGraphic أو الـMOGRT وإصدار Premiere. **لا نعتبرها مُعتمدة للإنتاج قبل اختبار عملي داخل Premiere.**

تشغيل اختبارات Native:
```
node --test tests/test_native_keyframes.js
```
مرجع API: https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/componentparam
